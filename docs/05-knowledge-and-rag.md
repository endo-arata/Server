# 05. ナレッジ基盤とRAG — 「データが無い」から始める

D-010: オーナーには取り込みたい既存データが無い。したがってこの基盤は
**「与えられたデータを検索する RAG」ではなく「自ら情報を集めて個人の知識体系を育てる RAG」**として設計する。

## 5.1 3つのナレッジ源

| 源 | 内容 | 生成主体 |
|---|---|---|
| **Self(自己生成)** | オーナーとの会話、指示、好み、決定、日課、家の状態 | 利用するだけで自然に蓄積 |
| **World(外部収集)** | オーナーの関心領域のニュース・論文・ドキュメント・製品情報 | AI が自律的に収集・要約・構造化 |
| **Connected(接続先)** | カレンダー、メール、GitHub、家電ログ、写真、健康データ | 連携を有効化した時点から流入 |

## 5.2 個人ナレッジモデル

```
Person(オーナー)
 ├─ Profile        好み・価値観・生活パターン(AI が推定、オーナーが訂正可能)
 ├─ Interests      関心トピック(重み付き。会話・閲覧・指示から学習)
 ├─ Projects       進行中の取り組み(このサーバー構築 等)
 ├─ People/Places/Things  エンティティと関係
 ├─ Timeline       出来事の時系列(会話・予定・家のイベント)
 └─ Decisions      決めたこと・保留していること(本計画書もここに入る)

World Knowledge
 ├─ Topic Wiki     関心トピックごとの「生きた」要約ページ(AI が毎日更新)
 ├─ Sources        原本(URL/PDF/動画)とその要約・引用
 └─ Digest         日次/週次ブリーフィング
```

## 5.3 パイプライン

```
[収集] RSS / Web / arXiv / GitHub / YouTube字幕 / Podcast → Playwright + API
   ▼
[正規化] HTML→Markdown, PDF→テキスト(OCR含む), 音声→文字起こし(Sense ノード)
   ▼
[抽出] T2 モデルが {要約, エンティティ, 関係, 関心スコア, 日付} を JSON で抽出
   ▼
[索引] 埋め込み(bge-m3/Qwen3-Embedding) → pgvector / 全文 → Postgres FTS / 関係 → グラフ
   ▼
[統合] Topic Wiki を差分更新(T0 が矛盾検出・古い記述の置換)
   ▼
[配信] 朝のブリーフィング(Discord/音声)、質問時の RAG 参照
```

## 5.4 検索(RAG)設計

- **ハイブリッド検索**: ベクトル + BM25(日本語は PGroonga/pg_bigm) + グラフ近傍 → リランカー
- **時間認識**: 新しい情報を優先しつつ「いつの話か」を回答に明示
- **出典必須**: 回答には必ず Source へのリンクと引用範囲を付ける
- **記憶の階層**: 短期(セッション) / 中期(直近数週間のサマリ) / 長期(Profile・Wiki)
- **忘却と訂正**: オーナーが「それは違う」と言えば Profile を即時更新し、履歴を残す

## 5.5 初期ブートストラップ(データが無い状態からの立ち上げ)

1. **インタビュー**: 初回に AI がオーナーに 20〜30 問の対話インタビューを行い、Profile と Interests の初期値を作る
2. **シード収集**: Interests に基づき、信頼できる情報源(公式ドキュメント・一次情報)から Topic Wiki を生成
3. **観察学習**: 利用ログから Interests の重みを更新(閲覧・質問・反応)
4. **週次レビュー**: AI が「今週学んだあなたのこと」「更新した Wiki」を提示し、訂正を受け付ける

## 5.6 初期 Topic Wiki(D-017)

| トピック | 主な情報源(英語含む) | 更新頻度 | 生成物 |
|---|---|---|---|
| AI/ML・ローカル LLM | arXiv (cs.CL/cs.LG), Hugging Face 新着, MLX/exo/llama.cpp リリース, Apple 開発者情報, 主要ラボのブログ, X/Reddit r/LocalLLaMA 要約 | 毎日 | 新モデル速報、ベンチ比較、本サーバーへの適用提案(Model Scout と連動) |
| ソフトウェア開発 | GitHub Trending, 言語/フレームワークのリリースノート, Hacker News, 技術ブログ | 毎日 | 注目 OSS、破壊的変更の警告、学習提案 |
| 投資・金融・経済 | 市況(日米)、企業決算、中銀・マクロ指標、信頼できる金融メディア | 市場時間中は随時、日次まとめ | 保有銘柄ダッシュボード(証券口座連携)、ニュースと保有の関連付け、**売買は絶対に自動実行しない** |
| ニュース・時事・生活 | 国内主要紙・NHK、海外主要紙、天気・災害、地域情報、製品/ガジェット | 毎朝・随時 | Morning Brief の中核、災害アラート |

- 英語ソースは原文を保存し、要約は日本語で生成(D-019)。専門用語は原語併記
- 投資トピックは「情報提供」に限定し、6章の権限モデルで取引を Forbidden 相当に固定(オーナーが明示的に解除しない限り)
