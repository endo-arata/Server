# 06. エージェント基盤と自律オートメーション

## 6.1 エージェントの階層

| 層 | 名前 | 役割 | 稼働 |
|---|---|---|---|
| L0 | **Concierge** | オーナーとの窓口。意図を理解し、下位に委任し、結果を報告 | 常駐 |
| L1 | **Specialists** | Research / Coder / Home / Media / Finance / Health 等の専門エージェント | オンデマンド |
| L2 | **Workers** | 単機能タスク(スクレイプ、変換、集計、テスト実行) | バッチ |
| BG | **Curator** | 5章のナレッジ更新を担当 | 夜間・空き時間 |
| BG | **Sentinel** | 監視・異常検知・自己修復(9章) | 常駐 |

## 6.2 権限モデル(Reversible automation の実装)

| レベル | 例 | 扱い |
|---|---|---|
| Read | 検索、参照、集計 | 自由 |
| Write-safe | ノート作成、下書き、リマインダ登録 | 自由、後で取り消し可 |
| Write-notify | カレンダー登録、照明ON/OFF、PR 作成 | 実行後に通知 |
| Approve | 送金、購入、削除、施錠解除、外部送信、クラウドAPI利用 | **事前承認必須**(Discord/Web でワンタップ) |
| Forbidden | 認証情報の書換、権限の自己拡張 | 基盤レベルで拒否 |

- 各エージェントには **トークン予算・時間予算・ツール許可リスト** を付与
- 全ツール呼び出しは監査ログへ。承認待ちは有効期限付き

## 6.3 実行基盤

- ランタイム: Python(MLX 親和性)で自作。Claude Agent SDK / MCP のプロトコルに準拠し、モデルを差し替え可能に
- ワークフロー: n8n(GUI で日課を組める)+ Temporal(長時間・再試行が必要なもの)
- サンドボックス: エージェントのコード実行は Linux VM/コンテナ内(ホストの macOS には触らせない)
- スケジューラ: cron 相当 + イベント駆動(Postgres `events` テーブル → LISTEN/NOTIFY)

## 6.4 初期の自律オートメーション候補(提案)

| 名前 | トリガ | 内容 |
|---|---|---|
| Morning Brief | 毎朝 | 天気・予定・ニュース要約・家の状態・昨夜のバックグラウンド成果を音声+Discord で |
| Inbox Triage | メール受信 | 分類・要約・返信下書き(送信は承認) |
| Repo Guardian | GitHub イベント | Issue 要約、PR レビュー、CI 失敗の原因推定と修正案 |
| Home Steward | センサー | 不在時の消し忘れ検知、帰宅前の空調、異常通知 |
| Media Librarian | ファイル追加 | 写真の顔/物体タグ付け、動画の文字起こし・章立て、重複整理 |
| Research Scout | 毎晩 | Interests に関する新着論文・記事を収集し Topic Wiki を更新 |
| Model Scout | 毎週 | 新モデルを Lab で評価し、Tier 昇格を提案 |
| Self-Heal | 異常検知 | サービス再起動、ディスク掃除、原因レポート |
| Weekly Review | 毎週日曜 | 今週の会話・行動・成果の振り返りと来週の提案 |
