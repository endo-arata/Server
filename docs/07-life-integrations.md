# 07. 生活を豊かにする連携カタログ(提案)

D-012: オーナーは「生活が豊かになるもの全て」を提案してほしいと回答。
以下をカタログ化し、次回以降の質問で **A(初期導入)/ B(第2期)/ C(保留)** に振り分ける。

## 7.1 オーナー指定分

| 領域 | 連携先 | AI が提供する価値 | 実装候補 |
|---|---|---|---|
| メッセージ | Discord(第一候補) / LINE / Telegram / Slack | どこからでも指示・通知・承認 | Discord Bot(discord.py)+ Slash コマンド+ボタン承認 |
| スマートホーム | Home Assistant + Matter/Zigbee/Wi-Fi 機器 | 音声で家を操作、状況に応じた自動化、異常検知 | HA を `studio-a` のコンテナで。Assist の会話エージェントをローカル LLM に |
| 開発 | GitHub / Claude Code / VS Code / Cursor | ローカルモデルでのコード生成・レビュー・CI 修正 | OpenAI 互換 API + MCP GitHub サーバー |
| メディア/NAS | 写真・動画・音楽・ドキュメント | 自動タグ・検索・文字起こし・整理 | Immich(写真)+ Jellyfin(動画)+ Sense ノード |

## 7.3 導入順序の考え方

1. **入口**(Discord + Web UI + 音声)を最初に。これが無いと他が使えない
2. **観察系**(カレンダー・メール読み取り・家のセンサー)で Self ナレッジを貯める
3. **実行系**(家電操作・PR 作成・買い物リスト)は権限モデルが固まってから
4. **創作・娯楽**は Lab ノードで並行して遊びながら育てる
